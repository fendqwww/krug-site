# ЭкоНива КРУГ — сайт концепта

Статический сайт (HTML/CSS/JS, без сборки) для QR-кода в презентации кейс-чемпионата «КЛЮЧ» 26/27.
Не официальный сайт ГК «ЭкоНива». Изображения продукта — 3D-визуализация концепта.

Запуск локально: `python3 -m http.server` в этой папке.
Деплой: Vercel → Add New → Project → выбрать репозиторий, Framework Preset: Other, без команды сборки.

Библиотеки: GSAP 3.12.5 + ScrollTrigger, Lenis 1.1.13 (лежат в `vendor/`). Шрифты Unbounded и Manrope (OFL).
